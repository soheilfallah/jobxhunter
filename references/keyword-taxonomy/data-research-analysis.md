# Keyword taxonomy — Data / research analysis (UK, entry–mid)

Use this as a KEYWORD PALETTE: match JD terms to profile evidence; flag missing must-haves as gaps.

**Weighting:** `W3` TITLE-MATCH · `W2` MUST-HAVE (essential) · `W1` NICE-TO-HAVE (desirable) ·
`[KO]` common KNOCKOUT.

Scope: data analyst, business/insight analyst, product analyst, research/BI analyst. Junior-to-mid.
Sector FLAVOUR matters — media, banking/financial-crime, public-sector governance each shift the
must-haves; detect sector and weight accordingly.

---

## HARD SKILLS
- `W2` SQL querying — the UNIVERSAL must-have; joins, aggregation, window functions, optimisation
  on large datasets. (In banking, `W2` Teradata may substitute/accompany.)
- `W2` Data analysis — turning complex data into insight
- `W2` Data visualisation / dashboarding — against business KPIs
- `W2` Reporting & insight communication — reports, presentations to non-technical stakeholders
- `W2` Data quality assessment — identifying gaps, validation/control checks
- `W1` Python for analytics — transformation, modelling
- `W1` Statistical analysis — descriptive stats, significance, segmentation
- `W1` Forecasting / predictive modelling
- `W1` Experiment evaluation — A/B tests, content/marketing/product experiments
- `W1` Data pipeline design / alignment; ETL (Extract, Transform, Load)
- `W1` Requirements gathering — translate business needs to data solutions
- `W1` Data specification / documentation
- `W1` Root-cause analysis
- `W1` Financial & operational analysis (sector-dependent)
- `W1` Data governance & compliance — records/data management (public-sector flavour)
- `W1` Report migration / data-platform migration (banking flavour)

## TOOLS / TECH
- `W2` SQL — must-have; dialects: T-SQL, PostgreSQL, MySQL, BigQuery SQL
- `W2` Teradata — banking/enterprise (essential where named)
- `W2` Microsoft Excel — table-stakes; pivots, formulas, Power Query
- `W2` Power BI · Tableau · Looker Studio — BI/visualisation (at least one, usually a must)
- `W1` Python — pandas, NumPy for analytics
- `W1` Jupyter notebooks
- `W1` R — statistical analysis
- `W1` Cloud data warehouses — BigQuery, Amazon Redshift, Databricks, Snowflake, GCP, AWS
  (differentiators)
- `W1` PowerPoint — stakeholder reporting/storytelling
- `W1` Bash — scripting
- `W1` Hadoop / Spark — big-data processing
- `W1` SAP S/4HANA / ECC — enterprise ERP data (sector-specific)
- `W1` Microsoft 365 / M365 Purview — data governance & compliance (public-sector, e.g. NHSPS)
- `W1` BPMN (Business Process Model and Notation) / UML (Unified Modeling Language) — process modelling
- `W1` CI/CD & containerisation (Docker, Kubernetes) — data-engineering-adjacent (nice at analyst
  level)
- `W1` dbt — analytics engineering / transformation

## CERTIFICATIONS / LICENCES
- `W1 [KO]` Degree gate — Bachelor's in Maths / Statistics / a quantitative field (stated as
  required in some posts, e.g. SThree). Not universal — many analyst roles hire on demonstrated
  skill.
- `W1` Vendor certs — Microsoft PL-300 (Power BI Data Analyst), Google Data Analytics, Tableau
  Desktop Specialist, Databricks, AWS/GCP data certs.
- `W2 [KO]` UK right-to-work / no sponsorship — common in public-sector and permanent roles.
- `W1 [KO]` Security clearance — BPSS/SC for public-sector/financial-crime data roles.
- `W1` SC / financial-crime domain knowledge (AML — Anti-Money Laundering; KYC — Know Your
  Customer; screening) for banking analyst roles.

## GENUINE SOFT SKILLS
(Include only when JD-named and profile-evidenced.)
- `W2` Stakeholder communication — presenting insight to non-technical audiences
- `W2` Storytelling with data — narrative from numbers
- `W2` Attention to detail — data accuracy
- `W1` Curious / critical mindset — questioning data, hypothesis-driven
- `W1` Collaboration — cross-functional, with engineering/product/business
- `W1` Problem-solving; commercial awareness (aligning analysis to business goals)
- `W1` Documentation / reproducibility discipline

## Sector-flavour cheat-sheet (re-weight must-haves by sector)
- **Media / broadcast / streaming** (e.g. ITV): audience & viewership metrics, VOD (video on
  demand) / SVOD (subscription VOD), content/marketing experiments, segmentation, forecasting;
  BigQuery + Looker Studio common. Foreground insight-storytelling.
- **Banking / financial services** (e.g. Barclays): SQL/Teradata heavy, financial-crime domain
  (AML/KYC/screening), report/platform migration, control & validation checks, senior-stakeholder
  engagement (AVP/VP/Director); often day-rate contract. Foreground rigour + governance.
- **Public sector / NHS** (e.g. NHS Property Services): Microsoft 365 & Purview, data governance,
  compliance, records/data management, supplier engagement; right-to-work + sometimes clearance.
  Foreground governance + compliance evidence.
- **Recruitment / consultancy / ops** (e.g. SThree): requirements gathering, data-pipeline
  alignment, data-quality assessment, financial/operational analysis; Maths degree may gate.

## Notes for the tailorer
- SQL is the anchor — surface it first whenever present. A BI tool (Power BI/Tableau/Looker) is
  the usual second must-have; Excel is assumed.
- Detect SECTOR and re-weight: media (audience/viewership metrics, VOD/SVOD), banking
  (Teradata, financial-crime/AML, report migration, day-rate contracts £250–400/day), public
  sector (M365 Purview, data governance, compliance). Foreground sector-matching evidence.
- Cloud warehouses (BigQuery/Redshift/Databricks) and Python are differentiators that lift a
  candidate above the entry pack — include when genuine.
- Pair acronyms: SQL (Structured Query Language), BI (business intelligence), ETL (extract-
  transform-load), KPI (key performance indicator), AML (anti-money laundering), M365 (Microsoft
  365), BPMN/UML.
