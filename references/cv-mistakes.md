# CV Failure Modes — Researched Catalog (UK-first)

Scope note: this document is the CV-specific failure catalog. The general voice/rewriting standard —
tone, rhythm, register, and AI-tell stripping of running text — is the writing model,
`references/writing-voice.md`. THIS doc supplies what the general model does not carry: the CV-domain
banned list, the verb allow-list, UK norms, and the recruiter-cited failure modes with fixes. Consult it
during audit and drafting, and apply it alongside the writing model.

Context that justifies the severity below: the Ladders eye-tracking study measured a
7.4-second initial screen; recruiters scan in an F-pattern (top lines + left edge), so the
first words of every bullet carry the load. A 379-recruiter survey put spelling/grammar as
the No.1 rejection trigger. A 2023 CV-Library survey: 92% of UK hiring managers rate
quantified achievements the most convincing CV element vs 8% for responsibilities alone.
Treat every failure mode here as something a real screener acts on, not a style nicety.

---

## 1. Corporate slop / buzzwords — the banned list

Never emit these. Each is a self-awarded trait, not evidence; recruiters see them hundreds
of times a week and discount them on sight. None appears as a requirement keyword in job
adverts, so they carry zero ATS-matching value — they cost space and credibility and buy
nothing. Novoresume, Teal, and recruiter blogs all report the same effect: one vague claim
makes the CV's *other* claims less believable.

| Banned term | Why it's discounted |
|---|---|
| results-driven | Self-assessment with no result attached; the results themselves should appear instead. |
| team player | Claimed by every candidate; unverifiable; show a team outcome instead. |
| passionate about | Emotion is not evidence; recruiters read it as filler for missing experience. |
| dynamic self-starter | Double cliché; describes nothing a screener can check. |
| go-getter | Slang-register trait claim; instantly reads as template text. |
| think outside the box | The cliché that proves the opposite; flagged as outdated by every buzzword survey. |
| synergy | Overused to the point of meaninglessness; corporate jargon with no referent. |
| hardworking | Baseline expectation, not a differentiator; Coburg Banks lists "hard-working intros" as a rejection reason. |
| detail-oriented | Ironically most often seen on CVs containing typos; prove it with an accuracy/QA metric. |
| motivated / driven / enthusiastic | Trait adjectives; interchangeable across all applicants, so they carry no information. |
| problem solver | Every job is problem-solving; name the problem you solved. |
| excellent communicator / people person | Unverifiable soft-skill claim; evidence is a presentation, negotiation, or stakeholder outcome. |
| proven track record | The record itself is what's wanted; the phrase without numbers is an admission there are none. |
| fast learner / adaptable / flexible | Entry-level filler; show a ramp-up ("productive on X within 4 weeks"). |
| innovative / creative / forward-thinking | Judgement words the reader must be allowed to conclude, not be told. |
| strategic / visionary | Senior-register self-praise; without a strategy outcome it reads as inflation. |
| natural leader | Leadership is shown by headcount, budget, or delivery — never self-declared. |
| seasoned professional | Outdated term; also ages the candidate (a UK bias hazard). |
| duties included / responsible for | Duty-speak — see §5; announces a task list, not impact. |
| leverage / utilise / paradigm / robust / core competency / value-added / mission-critical / disrupt | Jargon-complexity words; simple language outperforms them and they parse as AI/consultant slop. |
| references available upon request | Wastes a line stating a default; flagged as outdated by recruiters. |
| Microsoft Office proficient | Assumed baseline for office roles; only list tools the advert actually names. |

AI-slop tells (2025–26 addition): "spearheaded", "championed", "orchestrated",
"collaborated cross-functionally", "drove strategic initiatives", "leveraged data to
inform decisions". 53% of recruiters say they can spot AI-written CVs; these verbs
repeating across applications — especially senior-register verbs on junior CVs — are the
tell, and "reads like ChatGPT" is now a rejection note. Use plain verbs plus the concrete
nouns AI never knows: actual tools, clients, constraints, figures.

Fix pattern for the whole category — convert trait to evidence:
- Before: "Passionate, results-driven team player with a proven track record."
- After: "Payroll administrator who cut month-end processing from 5 days to 2 across 3,000 employees."

## 2. Strong-verb allow-list

Open every bullet with one of these (past tense for past roles, present for current
duties). One strong verb per bullet, verb matched to the function of the claim, then a
result. Vary verbs — repetition reads as template. UK spellings throughout (analysed,
organised, optimised — never analyzed/organized).

**Built / made (engineering, delivery):** built, engineered, designed, developed,
implemented, launched, shipped, automated, migrated, integrated, refactored, deployed,
configured, constructed, established, founded, created, produced.

**Analysed / evidenced (research, data, finance):** analysed, quantified, modelled,
forecast, audited, evaluated, benchmarked, tested, validated, investigated, diagnosed,
mapped, researched, reconciled.

**Led / coordinated (people, projects):** led, managed, coordinated, chaired, directed,
supervised, mentored, trained, recruited, delegated, negotiated, presented, persuaded,
partnered with, briefed.

**Improved / moved a number (impact verbs — strongest openers):** increased, reduced, cut,
grew, saved, accelerated, streamlined, halved, doubled, eliminated, consolidated,
delivered, exceeded, won, secured, resolved.

Weak verbs these replace — never open a bullet with: "responsible for", "helped with",
"worked on", "assisted", "participated in", "involved in", "tasked with", "handled",
"dealt with", "supported", "was part of", "duties included". Novoresume's survey verdict:
these "fail to show what the candidate actually accomplished."

- Before: "Responsible for the company newsletter."
- After: "Wrote and sent a fortnightly newsletter to 12,000 subscribers; grew open rate from 18% to 31%."

## 3. Concrete-over-abstract rules

Abstract claims are unfalsifiable, so screeners skip them; concrete details are what get
remembered and probed at interview. UK university careers services (Warwick, Reading) are
blunt: unsupported claims make the candidate *less* credible.

Rules:
- Every claim must carry at least one of: a number, a named tool/method, a named
  deliverable, or a named audience/client. No naked adjectives.
- Name the thing. "CRM" → "Salesforce"; "programming" → "Python/pandas"; "stakeholders" →
  "heads of Finance and Ops"; "a large team" → "a team of 9".
- State scale and context: employer sector/size in one line per role (Coburg Banks:
  "lack of employer info" is a rejection reason), then your slice of it.
- Superlatives need a source: "top-performing" only survives as "top of 14-person sales
  team, Q3 2025". StandOut CV files "Best salesman in Europe"-style lines under wild
  unproven claims.
- Let the reader conclude the trait. Evidence of shipping under deadline says "reliable";
  writing "reliable" says nothing.

- Before: "Strong analytical skills and experience with data tools."
- After: "Built Power BI dashboards over a 2m-row sales dataset, replacing a weekly manual Excel report for 40 users."

## 4. Vague unquantified claims

"Improved efficiency" without a number is a claim any applicant can make; with a number it
is testimony. 40% of recruiters call failure to quantify the single biggest CV mistake;
34% treat missing result statements as a dealbreaker; quantified bullets raise interview
odds by up to 40%.

Rules:
- Attach a metric to every achievement bullet: % (change, growth, savings), £ (revenue,
  budget, cost cut — pounds, not dollars), time (hours saved, deadline beaten), or volume
  (users, tickets, transactions, headcount).
- Percentages compare, raw numbers give scale — where possible give both: "cut errors 60%
  (from ~50 to ~20 a month)".
- Estimates are fine and normal: "approximately", "around 200 a week". An estimated
  number beats a vague adjective; a precise number with nothing behind it is §10 territory.
- If a bullet truly has no measurable outcome, quantify the scope instead (team size,
  budget, frequency, caseload) — or cut the bullet.

- Before: "Improved efficiency of the reporting process."
- After: "Automated monthly reporting in Python, cutting preparation time from 3 days to 4 hours (~£9k/year staff time saved)."

## 5. Responsibilities instead of achievements

A duty list describes the job; the screener already knows the job — they wrote the advert.
What they cannot get elsewhere is what happened because *this person* did it. CV-Library's
survey: 92% of UK hiring managers find quantified achievements the most convincing element;
8% are convinced by responsibilities.

Rules:
- Convert with the "so what" test: duty + method + outcome. Keep asking "and what
  changed?" until a result appears.
- Ration: aim for achievement-led bullets on recent roles; a one-line scope sentence can
  carry the duties ("Managed the 6-person service desk, ~900 tickets/month"), freeing
  bullets for outcomes.
- Weight recency: recruiters study the current/latest role hardest (StandOut CV ranks
  thin current-role detail among the highest-damage mistakes). Most detail on the last
  role; older-than-10-years roles compress to one or two lines.
- Never paste the job description into the CV — screeners recognise their own adverts.

- Before: "Duties included producing financial reports and liaising with auditors."
- After: "Produced monthly management accounts for 3 business units and closed the annual audit with zero adjustments — first clean audit in 4 years."

## 6. ATS-breaking formatting (brief — detail in ats-mechanics.md)

Kept short here; full parser mechanics, tested layouts, and file-format guidance live in
ats-mechanics.md. The headline failure modes recruiters and ATS vendors cite:

- **Tables, columns, text boxes** — parsers read linearly and slice across cells
  ("text-layer scrambling" → word salad). Single column, top-to-bottom.
- **Headers/footers** — many parsers skip them; TopResume found contact details missed 25%
  of the time when placed there. Contact block goes in the body.
- **Graphics, skill graphs, icons, photos, logos** — parse as gibberish or nothing; skill
  bars also carry no scale for humans ("3 years of SQL" beats a 4/5 star bar).
- **Non-standard fonts / decorative bullets** — can render as [NULL]; use Arial, Calibri,
  or Georgia and plain round bullets.
- **Exotic file formats** — send .docx or a text-based PDF as the advert requests; never
  an image or scanned PDF.
- Standard UK section headings ("Work Experience", "Education", "Skills") — cleverness
  breaks section detection.

- Before: two-column template, contact details in the page header, skills as star ratings.
- After: single column, contact block at top of body, skills as a comma-separated list with years/level.

## 7. Tense and date inconsistencies

Mixed tenses and mismatched date formats read as carelessness in a document whose whole
job is to demonstrate care; missing or inaccurate dates read as concealment (Coburg Banks
lists them as a standalone rejection reason).

Rules:
- Current role: present tense for ongoing duties ("manage", "lead"); past tense for
  completed achievements even inside the current role ("delivered the 2025 migration").
- All previous roles: past tense, no exceptions.
- Never mix tenses within one bullet or one role's duty list.
- One date format everywhere: "Mar 2022 – Present" style; month + year, en dash, same
  separator on every role and every qualification. Never mix "03/2022", "March 22" and
  "2022–present" in one CV.
- Reverse-chronological order, current role first — any other ordering is read as hiding
  something.
- Gaps over ~3 months: account for them in one neutral line (travel, carer's leave,
  study). Unexplained gaps invite the worst assumption.

- Before: "Jan 2020 - present: Managed a team of five and I am overseeing the budget."
- After: "Jan 2020 – Present: Manage a team of 5 with a £250k budget; delivered the 2024 CRM migration two weeks early."

## 8. Padding and over-length

UK norm: two full A4 pages (Reading careers service: "most CVs should be two full pages").
One page is fine for early-career and expected in investment banking; three-plus is
academic-CV-with-publications territory only. Recruiters call over-long CVs "War & Peace"
— length buries the good material below the 7-second scan.

Cut, in order:
1. Anything on the §1 banned list, and every empty intro sentence.
2. Detail on roles older than ~10 years — compress to title, employer, dates, one line.
3. Repetition: the same skill proven twice keeps only the stronger instance.
4. Defaults and non-content: "references available on request", full postal address (town
   or city only), DOB/age, marital status, nationality, photo (all standard UK exclusions —
   Equality Act bias norms), reasons for leaving, salary.
5. Irrelevant hobbies. Keep an interest only if it evidences a job-relevant trait, and
   never a strange or divisive one.
- Also cut long paragraphs as a form: dense blocks are padding even when the words aren't.
  Bullets of one to two lines; personal profile 3–4 lines maximum.
- Do not "fix" length with 9pt text or vanishing margins — 11pt+ and white space are
  legibility norms; earn the space by cutting content instead.

- Before: three pages including a 2009 retail job with six bullets and an "Interests: socialising, films" section.
- After: two pages; the 2009 role is one line; the freed space extends the current role's achievements.

## 9. Generic / untailored content

Failure to tailor is the mistake UK sources rank most damaging of all (StandOut CV: "if
you only address one mistake, make it this one"). Recruiters spot a blast CV instantly —
it answers none of the advert's requirements in its first half-page — and generic CVs also
score poorly on ATS keyword match.

Rules:
- Mirror the advert's exact vocabulary for skills the candidate genuinely has (their
  "stakeholder management" not your "client liaison") — humans and ATS both match on the
  advert's terms.
- Re-order, don't just re-word: the requirements the advert lists first should be
  evidenced in the profile and the top bullets of the most recent role.
- Rewrite the personal profile per application; a profile that could open any application
  ("results-driven professional seeking a challenging role") is the tell recruiters cite.
- Cut experience irrelevant to *this* role rather than keeping everything "just in case".
- No keyword stuffing: keywords go inside true achievement sentences, never in white text
  or a keyword dump — stuffing fails human review even where it passes the parser.
- Applying at all must be plausible: "chancing your arm" at clearly unsuitable roles burns
  the candidate's name with that recruiter.

- Before: one profile for every application: "Versatile graduate seeking an exciting opportunity in a dynamic organisation."
- After: "Economics graduate with 12 months' credit-risk placement experience at a UK retail bank; built the SQL loss-forecasting queries now used by the 8-person risk team" — for a credit-risk analyst advert naming SQL and forecasting.

## 10. Over-claiming red flags

UK background screening checks dates, titles and qualifications, and recruiters pattern-match
inflation and discount the whole document when they see it.

Red flags screeners act on:
- Dates massaged to hide gaps or stretch tenures — checks surface these first.
- Title inflation ("Head of..." for a team of none); claiming the team's output as solo
  work ("I" for what was "we").
- Skill-list stuffing with tools the candidate couldn't survive an interview question on.
- Suspiciously round or enormous unverifiable numbers ("saved £2m") with no mechanism —
  pair every big number with how it was achieved and your specific role in it.
- Senior-register AI verbs on a junior history (§1) — reads as slop.
- Unverifiable superlatives ("best in the region") — see §3.

Rules: claim only what survives a competency interview and a reference call; scale "led"
down to "coordinated" or "contributed to" where true; estimates marked as estimates;
qualifications stated exactly (grade, body, year).

- Before: "Led the company's digital transformation, saving £2m."
- After: "One of 4 analysts on the finance-systems migration; built the reconciliation checks that cut month-end close by 2 days."

## 11. Contact, typo and small-format errors — the things that bin a CV

The cheapest rejections. A 379-recruiter survey ranked spelling and grammar the No.1
rejection trigger; over half of UK CVs are reported rejected for errors. These cost
nothing to fix and everything to miss.

- **Typos and grammar** — fatal in a two-page document that claims attention to detail.
  Full proofread pass; spellcheck set to UK English; read aloud; check the words
  spellcheck can't ("manger" for "manager", "form" for "from").
- **US spellings** — "organized", "analyzed", "center", "$" read as errors to UK
  screeners and can even mismatch ATS keywords; UK spellings and £ throughout. It is a
  CV, not a résumé.
- **Wrong or dead contact details** — one wrong digit ends the application silently.
  Verify phone and email character by character; include LinkedIn only if it's current
  and consistent with the CV.
- **Unprofessional email address** — "bigguns88@..." makes judgement the issue; use a
  plain firstname.lastname address.
- **Wrong company or role name left in** from the last application — instant rejection;
  search the document for every previous employer's name before sending.
- **Template debris** — placeholder text ("[insert achievement]") or template
  instructions left in; reads as sloppy autopilot.
- **File naming** — send "Jane-Smith-CV.pdf", not "Document1.docx" or "CV_final_v7".
- **Inconsistent micro-formatting** — mixed fonts, mixed bullet glyphs, drifting
  indentation, headings styled three ways, ragged page breaks mid-role. One font, one
  bullet style, deliberate page transitions.
- **Third-person narration** ("Jane is a dedicated professional...") — reads as awkward
  and grandiose; write first person with the pronouns mostly implied ("Led...", not "I
  led..." every line).
- **Photo, DOB, marital status, full address, NI number** — UK exclusions (bias norms +
  identity-theft risk); their presence marks the CV as non-UK or out of date.

Final gate before output: run this catalog as a checklist — §1 scan for banned terms, §2
verb check on every bullet opener, §4 number check on every achievement, §7 tense/date
sweep, §11 detail sweep. A CV that clears all eleven categories is ready for the
writing-model voice pass (`references/writing-voice.md`), not before.
