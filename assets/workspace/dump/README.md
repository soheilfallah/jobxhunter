# dump

Put everything you have about your working life in this folder, in any format and any language.
Messy is fine.

- old CVs and résumés, any version
- a LinkedIn export (Profile, then Save to PDF)
- certificates, licences, transcripts
- cover letters you have sent
- notes about what you did in each job, especially numbers
- adverts for jobs you liked

Add one short note saying where you live, your right to work, and the kinds of jobs you want.

Then run `/jobxhunter:intake`. Add more files later and run it again: it only adds what is new.
