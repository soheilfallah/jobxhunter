# Indeed (no key)

Indeed is built into Claude. You connect it once with your Claude account; there is nothing to copy.

1. Open <https://claude.ai/settings/connectors>.
2. Find **Indeed** in the list and click **Connect**.
3. Approve the access it asks for.
4. Restart Claude Code so the Indeed tools load.
5. Run `/jobxhunter:setup` again. `STATUS.md` should show Indeed as working.

**If it does not show up:** the connector is tied to the Claude account you are signed in with.
Check Claude Code is signed in to the same account (`/status`), then restart once more.

**Dice** (US-leaning tech roles) connects the same way from the same page. It is only worth adding
for software, data and AI roles.
