## Web supplement — SIA (security)
- GOV.UK: front-line licence types requiring licence-linked qualification = security guarding, door supervision, close protection, public space surveillance (CCTV). DS/CP/SG cover incidental CCTV to ID trespasser/protect property; standalone CCTV (PSS) licence needed if using CCTV to guard against disorder/protect people. Licence fee £204 from 1 Apr 2026; lasts 3 years. 2026 updates: mandatory refresher quals on renewal, stricter first-aid prerequisites, counter-terrorism (ACT Awareness / SCaN) + vulnerability awareness training. NLW 1 Apr 2026 = £12.71/hr (floor for frontline pay). Sources: https://www.gov.uk/guidance/find-out-if-you-need-an-sia-licence , https://www.gov.uk/guidance/apply-for-an-sia-licence
